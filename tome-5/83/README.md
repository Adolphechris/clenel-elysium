# 83. Dépendances — avec les Tomes 4, 7, 11

## Objet
Définir les dépendances majeures du Tome 5.

## Dépendances principales
- Tome 4 : programmes, niveaux, options, filières, règles académiques ;
- Tome 7 : architecture technique, API, sécurité, infrastructure ;
- Tome 11 : exploitation, administration système, supervision.

## Exigences
- cohérence bidirectionnelle ;
- mise à jour en cas d'évolution d'un tome voisin ;
- compatibilité avec la Constitution et la feuille de route.

## Résultat attendu
Un socle fonctionnel aligné sur l'ensemble du projet.
