# 72. Module Ressources humaines internes

## Objet
Définir le suivi du personnel interne à l'établissement.

## À couvrir
- profils ;
- affectations ;
- services ;
- présences ;
- charges ;
- évolutions de poste ;
- documents internes.

## Exigences
- servir l'administration ;
- respecter la hiérarchie ;
- conserver les traces d'action ;
- ne pas empiéter sur les décisions disciplinaires.

## Résultat attendu
Un référentiel RH interne clair.
