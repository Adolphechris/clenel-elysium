# 74. Module Tuteur IA

## Objet
Définir la fonction d'assistance pédagogique de l'IA.

## À couvrir
- aide à la compréhension ;
- remédiation guidée ;
- suggestions de parcours ;
- quiz d'entraînement ;
- recommandations de ressources.

## Exigences
- l'IA assiste mais ne décide pas seule ;
- aucune validation définitive automatique ;
- traçabilité des recommandations ;
- alignement sur le Tome 8.

## Résultat attendu
Une IA utile, encadrée et non souveraine.
