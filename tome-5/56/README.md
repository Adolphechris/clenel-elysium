# 56. Conformité avec la Constitution

## Objet
Établir les règles de conformité constitutionnelle qui gouvernent tout le Tome 5.

## Ce que ce sous-tome doit couvrir
- traçabilité ;
- protection des données ;
- intégrité des résultats ;
- validation humaine ;
- audit et contestation ;
- sécurité des flux sensibles.

## Exigences fonctionnelles
- journaliser les actions critiques ;
- conserver l'historique des versions ;
- empêcher toute décision sensible sans autorité humaine ;
- permettre la reconstitution d'un parcours.

## Points d'attention
- pas d'automatisme décisionnel définitif ;
- pas de dérogation implicite ;
- pas d'exception silencieuse.
