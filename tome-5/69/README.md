# 69. Module Devoirs et travaux à rendre

## Objet
Définir la publication, le dépôt et la correction des travaux.

## À couvrir
- devoirs ;
- dépôts ;
- échéances ;
- corrections ;
- retours pédagogiques ;
- retards.

## Exigences
- gérer plusieurs fichiers ;
- tracer les versions ;
- notifier les échéances ;
- conserver les commentaires de correction.

## Résultat attendu
Un circuit de devoirs clair et contrôlé.
