# 55. Périmètre du Tome 5 — vision fonctionnelle globale

## Objet
Définir le périmètre fonctionnel du système ELLLYSIUM et ses grands usages.

## Ce que ce sous-tome doit couvrir
- les profils utilisateurs pris en charge ;
- les grands axes fonctionnels ;
- la frontière entre fonctionnel, pédagogique et technique ;
- la logique d'unification entre secondaire, université et établissements.

## Portée fonctionnelle
Le Tome 5 couvre exclusivement les fonctions métier. Il décrit :
- ce qui doit être possible dans le système ;
- qui peut le faire ;
- dans quel ordre ;
- avec quelles validations ;
- avec quelles traces ;
- et sous quelles limites.

Il ne définit pas :
- l'architecture technique détaillée ;
- l'ergonomie écran par écran ;
- les contenus pédagogiques ;
- les règles académiques de fond déjà posées dans le Tome 3 et le Tome 4.

## Exigences fonctionnelles
- une seule expérience d'entrée pour les personnes et les établissements ;
- des parcours distincts selon le rôle ;
- une lecture claire des responsabilités ;
- une compatibilité avec les tomes voisins.

## Cas d'usage de référence
- un apprenant crée un compte, choisit un profil et rejoint un parcours ;
- un établissement déclare sa structure et rattache ses membres ;
- un enseignant accède à ses classes, notes et notifications ;
- une direction pilote les admissions, résultats et documents ;
- un parent suit le parcours d'un élève sans accéder aux informations réservées.

## Règles de rédaction
- ne pas confondre capacité fonctionnelle et implémentation ;
- ne pas anticiper des modules non validés par la feuille de route ;
- conserver un langage institutionnel, précis et stable.

## Contraintes structurantes
- le système doit rester compréhensible par les non-techniciens ;
- chaque module doit pouvoir évoluer sans casser les autres ;
- les actions sensibles doivent toujours laisser une trace ;
- les décisions finales à effet académique restent humaines ;
- les fonctions doivent être compatibles avec l'usage à distance et le faible débit.

## Livrables attendus
- portée fonctionnelle ;
- exclus du périmètre ;
- acteurs concernés ;
- dépendances de haut niveau.

## Critère d'acceptation
Ce sous-tome est considéré conforme si tout lecteur peut identifier le rôle du Tome 5 dans l'ensemble du projet sans le confondre ni avec le Tome 3, ni avec le Tome 4, ni avec le Tome 7.
