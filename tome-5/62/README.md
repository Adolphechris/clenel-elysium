# 62. Module Gestion des classes, promotions et groupes

## Objet
Définir l'organisation interne des classes, promotions et groupes.

## Ce que ce sous-tome doit couvrir
- création de classes ;
- passage annuel ;
- groupes pédagogiques ;
- sous-groupes de travail ;
- affectation des enseignants ;
- archivage des structures closes.

## Règles d'organisation
Le système doit permettre de représenter :
- une classe comme unité pédagogique de base ;
- une promotion comme cohorte de progression ;
- un groupe comme sous-ensemble fonctionnel ;
- un sous-groupe comme variation temporaire ou méthodologique.

## Exigences
- cohérence avec les règles pédagogiques ;
- compatibilité avec les décisions de jury ;
- gestion des migrations et des changements de niveau.

## Cas d'usage
- ouverture d'une nouvelle classe ;
- réaffectation d'élèves ;
- passage annuel ;
- division en groupes de travaux ;
- fermeture d'une structure.

## Contraintes
- éviter les doublons de structure ;
- maintenir la correspondance avec les référentiels pédagogiques ;
- conserver l'historique des affectations ;
- ne pas confondre changement administratif et changement académique.

## Résultat attendu
Une organisation académique structurée et stable.

## Critère d'acceptation
Le module est conforme si toute classe, promotion ou groupe peut être retracé dans le temps avec ses membres, ses affectations et son état.
