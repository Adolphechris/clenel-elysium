# 65. Module Cahier de présence

## Objet
Définir la saisie et le suivi de la présence, des absences et des retards.

## À couvrir
- présence ;
- absence ;
- retard ;
- sortie anticipée ;
- justification ;
- alertes d'assiduité.

## Exigences
- tracer chaque séance ;
- calculer les taux d'assiduité ;
- signaler les seuils critiques ;
- historiser les motifs et justificatifs.

## Résultat attendu
Un suivi de présence exploitable pour le pilotage académique.
