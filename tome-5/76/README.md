# 76. Module Délivrance des diplômes et attestations

## Objet
Définir la production des attestations et documents de fin de parcours.

## À couvrir
- attestations ;
- certificats intermédiaires ;
- relevés validés ;
- diplômes ou documents équivalents ;
- numérotation ;
- signature ;
- archivage ;
- annulation.

## Exigences
- délivrance conditionnée ;
- contrôle final humain ;
- traçabilité documentaire ;
- compatibilité avec le cadre de reconnaissance applicable.

## Résultat attendu
Un circuit documentaire de sortie sécurisé.
