# 67. Module Calcul académique automatique

## Objet
Définir les calculs automatiques liés aux résultats académiques.

## À couvrir
- moyennes ;
- pondérations ;
- crédits ;
- compensations ;
- classements ;
- mentions ;
- alertes.

## Exigences
- s'aligner sur le Tome 3 et le Tome 4 ;
- rester paramétrable ;
- laisser les décisions sensibles au jury humain ;
- tracer les règles appliquées.

## Résultat attendu
Un moteur de calcul transparent et cohérent.
