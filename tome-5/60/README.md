# 60. Module Dossier numérique

## Objet
Définir le dossier numérique unifié pour apprenant, étudiant et enseignant.

## Contenu du dossier
- identité ;
- coordonnées ;
- justificatifs ;
- parcours ;
- états administratifs ;
- documents générés ;
- historique des actions ;
- traces de validation.

## Exigences
- dossier unique par personne ;
- historique complet ;
- consultation par droit ;
- export contrôlé ;
- protection contre les altérations.

## Résultat attendu
Un référentiel personnel stable et auditable.
