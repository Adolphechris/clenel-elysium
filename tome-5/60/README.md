# 60. Module Dossier numérique

## Objet
Définir le dossier numérique unifié pour apprenant, étudiant et enseignant.

## Contenu du dossier
- identité ;
- coordonnées ;
- justificatifs ;
- parcours ;
- états administratifs ;
- documents générés ;
- historique des actions ;
- traces de validation.

## Structure du dossier
Le dossier doit comporter au minimum :
- une identité de référence ;
- un bloc administratif ;
- un bloc académique ;
- un bloc documentaire ;
- un bloc de communications ;
- un bloc d'historisation ;
- un bloc de permissions.

## Exigences
- dossier unique par personne ;
- historique complet ;
- consultation par droit ;
- export contrôlé ;
- protection contre les altérations.

## Règles de conservation
- chaque modification doit créer ou mettre à jour une version historisée ;
- les documents supprimés doivent rester traçables ;
- les états antérieurs doivent pouvoir être consultés par les autorités compétentes ;
- le dossier doit conserver la mémoire des changements d'établissement, de classe, de filière ou de rôle.

## Cas d'usage
- un étudiant consulte ses relevés ;
- un enseignant met à jour ses pièces professionnelles ;
- une direction vérifie le parcours d'un élève ;
- un secrétariat prépare un document administratif ;
- un parent consulte uniquement les champs qui lui sont autorisés.

## Résultat attendu
Un référentiel personnel stable et auditable.

## Critère d'acceptation
Le dossier numérique est conforme s'il devient la source centrale de référence sans supprimer l'historique ni les traces utiles à l'audit.
