# 70. Module Communication

## Objet
Définir les échanges internes et institutionnels.

## À couvrir
- messagerie ;
- annonces ;
- notifications ;
- accusés de lecture ;
- messages urgents.

## Exigences
- filtrer selon les droits ;
- garder la traçabilité ;
- modérer les communications sensibles ;
- éviter les notifications inutiles.

## Résultat attendu
Un canal de communication utile et maîtrisé.
