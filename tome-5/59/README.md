# 59. Module Inscriptions et admissions

## Objet
Définir les flux d'inscription et d'admission pour tous les profils.

## Cas à couvrir
- apprenant indépendant ;
- élève affilié ;
- création d'établissement ;
- rattachement d'un membre ;
- reprise après correction.

## Exigences
- collecte minimale des données nécessaires ;
- dépôt et contrôle des pièces ;
- validation motivée ;
- rejet explicite et traçable ;
- conformité au niveau d'étude demandé.

## Sortie attendue
Un dossier d'admission complet et exploitable par les instances humaines.
