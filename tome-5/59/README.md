# 59. Module Inscriptions et admissions

## Objet
Définir les flux d'inscription et d'admission pour tous les profils.

## Cas à couvrir
- apprenant indépendant ;
- élève affilié ;
- création d'établissement ;
- rattachement d'un membre ;
- reprise après correction.

## Processus d'admission
Le processus doit suivre une logique simple et constante :
1. dépôt de la demande ;
2. dépôt des pièces ;
3. vérification de complétude ;
4. analyse de conformité ;
5. validation ou rejet motivé ;
6. activation du dossier.

## Exigences
- collecte minimale des données nécessaires ;
- dépôt et contrôle des pièces ;
- validation motivée ;
- rejet explicite et traçable ;
- conformité au niveau d'étude demandé.

## Règles de gestion
- une demande incomplète doit rester en attente et non être acceptée par défaut ;
- une admission ne peut pas être définitive sans validation humaine ;
- le système doit proposer des corrections lorsqu'un dossier est récupérable ;
- le motif de rejet doit être archivé ;
- les admissions doivent respecter les équivalences et les prérequis.

## Pièces typiques
- identité ;
- preuve du niveau antérieur ;
- photographie ou équivalent légal ;
- contacts ;
- autorisations nécessaires ;
- documents spécifiques à l'établissement ou à la filière.

## Sortie attendue
Un dossier d'admission complet et exploitable par les instances humaines.

## Critère d'acceptation
Le module est acceptable si aucun dossier ne peut devenir actif sans preuve de contrôle, d'affectation claire et de décision traçable.
