# 73. Module Bibliothèque numérique et ressources OER

## Objet
Définir la bibliothèque et les ressources pédagogiques ouvertes.

## À couvrir
- cours ;
- documents ;
- vidéos ;
- supports téléchargeables ;
- ressources libres ;
- ressources validées.

## Exigences
- gérer les métadonnées ;
- contrôler les accès ;
- versionner les contenus ;
- supporter le mode hors ligne lorsque pertinent.

## Résultat attendu
Une bibliothèque utile, riche et gouvernée.
