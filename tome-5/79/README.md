# 79. Workflows transversaux

## Objet
Définir les chaînes de traitement de bout en bout.

## Chaînes à couvrir
- inscription → vérification → validation → accès ;
- affectation → emploi du temps → présence → note ;
- note → calcul → validation → bulletin ;
- dossier → critères → validation → document final.

## Exigences
- états intermédiaires ;
- points de contrôle ;
- rejets ou retours ;
- journalisation systématique.

## Résultat attendu
Des flux métiers cohérents et lisibles.
