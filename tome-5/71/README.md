# 71. Module Caisse et gestion financière

## Objet
Définir la gestion des frais, paiements et échéanciers.

## À couvrir
- frais ;
- factures ;
- paiements ;
- échéanciers ;
- remises ;
- soldes ;
- relances.

## Exigences
- supporter la gratuité ;
- supporter les aides et exonérations ;
- séparer le financier de l'académique ;
- tracer toute opération monétaire.

## Résultat attendu
Une gestion financière exploitable sans ambiguïté.
