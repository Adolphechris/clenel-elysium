# 81. Gestion des exceptions

## Objet
Définir les cas particuliers du parcours académique.

## À couvrir
- transfert ;
- abandon ;
- interruption ;
- reprise ;
- redoublement ;
- changement de filière ou d'option ;
- suspension administrative.

## Exigences
- chaque exception doit produire un état clair ;
- la décision sensible reste humaine ;
- la trace doit être conservée ;
- les règles doivent rester compatibles avec le Tome 4.

## Résultat attendu
Une gestion formelle des cas non standards.
