# 80. Gestion des droits et permissions

## Objet
Définir la matrice d'accès et les règles RBAC.

## À couvrir
- rôles ;
- permissions ;
- périmètres ;
- restrictions contextuelles ;
- révocation ;
- validation des actions sensibles.

## Exigences
- moindre privilège ;
- séparation des responsabilités ;
- journalisation systématique ;
- lisibilité et maintenance.

## Résultat attendu
Une gouvernance des accès robuste.
