# Fondations de référence d'ELLYSIUM

Ce dossier constitue la base de travail commune pour la suite du projet. Il ne remplace pas les tomes 1 à 3, mais les traduit en cadre d’exécution opérationnel pour les tomes à venir.

## Rôle de ce dossier

- conserver la cohérence institutionnelle avec le Tome 1 et le Tome 2 ;
- fixer les principes de fonctionnement issus du Tome 3 ;
- servir de socle à la construction des tomes 4 et suivants ;
- permettre une transition progressive du cahier des charges vers une architecture de mise en œuvre.

## Principes de référence

1. L’accès à l’éducation de qualité est un droit fondamental.
2. La qualité pédagogique prime sur la rapidité de mise en œuvre.
3. Les données, les parcours et les décisions doivent être traçables.
4. L’intelligence artificielle est un outil d’assistance, pas une autorité autonome.
5. Les décisions académiques et disciplinaires restent humaines.
6. Les modules techniques et pédagogiques doivent être conçus de manière cohérente avec la Constitution d’ELLYSIUM.

## Structure du socle

- Fondements institutionnels : vision, mission, gouvernance, valeurs.
- Fondements pédagogiques : parcours, contenus, évaluation, accompagnement.
- Fondements fonctionnels : rôles, modules, workflows essentiels.
- Fondements techniques : sécurité, données, intégrité, traçabilité.
- Fondements d’opération : gouvernance, lancement pilote, qualité, amélioration continue.

## Utilisation future

Les tomes 4 et suivants doivent s’appuyer sur ce socle sans le contredire. Les futurs documents devront être rédigés de manière à être cohérents avec :

- la Constitution d’ELLYSIUM (Tome 2) ;
- la philosophie pédagogique (Tome 3) ;
- la structure de référence établie ici.
