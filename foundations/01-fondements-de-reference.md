# Fondements de référence d'ELLYSIUM

## 1. Objet du document

Ce document pose la base de travail commune du projet en partant des tomes 1, 2 et 3 déjà rédigés. Il ne remplace pas ces tomes ; il les organise en un cadre de mise en œuvre pour les tomes suivants.

## 2. Fondation institutionnelle

### 2.1 Vision
ELLYSIUM est une institution éducative numérique qui rend l’enseignement secondaire et universitaire accessible à toute personne exclue par le coût, la distance ou l’isolement géographique, tout en modernisant la gestion des établissements scolaires.

### 2.2 Mission
ELLYSIUM a pour mission de :
- offrir un enseignement de qualité à distance ;
- accompagner les apprenants individuellement ou via leurs établissements ;
- fournir aux écoles un système de gestion complet ;
- garantir une gouvernance fiable, transparente et traçable.

### 2.3 Valeurs fondatrices
Les valeurs de référence sont les suivantes :
- intégrité ;
- excellence ;
- égalité des chances ;
- responsabilité ;
- innovation ;
- transparence ;
- respect de la personne ;
- inclusion ;
- solidarité ;
- service de la connaissance.

## 3. Principes normatifs

### 3.1 Principes non négociables
Les principes suivants doivent guider toutes les décisions futures :
- qualité pédagogique ;
- protection des apprenants ;
- protection des données ;
- traçabilité des décisions ;
- accessibilité ;
- amélioration continue ;
- intégrité scientifique ;
- transparence ;
- respect de la dignité humaine.

### 3.2 Règle d’usage de l’intelligence artificielle
L’IA doit être utilisée comme un outil d’assistance pédagogique et administrative. Elle ne remplace pas les décisions humaines. Les décisions académiques, disciplinaires ou administratives définitives restent sous responsabilité humaine.

## 4. Acteurs du système

### 4.1 Apprenant
L’apprenant est au centre du dispositif. Il doit pouvoir :
- s’inscrire et se connecter ;
- consulter les cours ;
- suivre ses progrès ;
- participer aux évaluations ;
- obtenir un suivi pédagogique adapté.

### 4.2 Établissement
L’établissement est un acteur institutionnel majeur. Il doit pouvoir :
- gérer ses élèves ;
- organiser ses enseignants ;
- suivre les résultats ;
- produire des bulletins et des rapports ;
- piloter ses opérations académiques et administratives.

### 4.3 Enseignant
L’enseignant a pour mission d’orienter, d’accompagner et d’évaluer. Il doit pouvoir :
- préparer et publier des contenus ;
- suivre la progression ;
- intervenir sur les évaluations ;
- communiquer avec les apprenants ;
- contribuer à l’amélioration du contenu pédagogique.

### 4.4 Administration
L’administration gère les processus institutionnels :
- inscriptions ;
- rôles utilisateurs ;
- accès ;
- communications internes ;
- suivi des opérations et des décisions.

## 5. Fondements pédagogiques de référence

### 5.1 Organisation du parcours
Le parcours pédagogique doit être organisé autour de :
- niveaux d’études ;
- filières ;
- unités d’enseignement ;
- modules ;
- cours ;
- leçons ;
- évaluations ;
- suivis de progression.

### 5.2 Modalités d’enseignement
L’enseignement doit être pensé comme :
- accessible ;
- asynchrone et synchrone selon les besoins ;
- adapté aux réalités de l’enseignement à distance ;
- compatible avec les environnements à faible débit ;
- compatible avec les téléphones intelligents et les ordinateurs.

### 5.3 Évaluation
L’évaluation doit être :
- régulière ;
- transparente ;
- équitable ;
- traçable ;
- cohérente avec les objectifs de formation.

## 6. Fondements fonctionnels de référence

### 6.1 Modules de base à prévoir
Les modules suivants constituent le cœur du système à construire :
- gestion des comptes et des rôles ;
- gestion des établissements ;
- gestion des apprenants ;
- catalogue de cours et de programmes ;
- parcours d’apprentissage ;
- évaluations et notes ;
- bulletins ;
- communications ;
- tableaux de bord académiques et administratifs.

### 6.2 Règles de cohérence fonctionnelle
Toute fonction future doit respecter les règles suivantes :
- un apprenant appartient à un parcours défini ;
- un cours appartient à une structure pédagogique claire ;
- une évaluation doit être liée à un objectif pédagogique ;
- une décision importante doit être historisée ;
- un utilisateur ne peut agir au-delà de ses droits.

## 7. Fondements techniques de référence

### 7.1 Exigences de sécurité
Le système doit garantir :
- l’authentification des utilisateurs ;
- la séparation des droits ;
- la protection des données sensibles ;
- l’historisation des actions importantes ;
- la traçabilité des décisions.

### 7.2 Exigences de qualité technique
Le système doit être :
- fiable ;
- maintenable ;
- évolutif ;
- conforme aux règles de qualité pédagogique et technique ;
- capable de supporter un déploiement progressif.

## 8. Fondements d’opération et de lancement

Le lancement doit se faire par étapes, en commençant par un périmètre maîtrisé et en s’appuyant sur :
- une gouvernance claire ;
- des établissements pilotes ;
- des parcours pédagogiques testés ;
- une boucle de feedback ;
- une amélioration continue.

## 9. Utilisation pour les tomes suivants

Les tomes 4 et suivants devront s’appuyer sur ce document pour :
- préciser les programmes d’études ;
- détailler l’architecture fonctionnelle ;
- choisir l’architecture technique ;
- définir les règles de sécurité et de gouvernance ;
- préparer le lancement réel du projet.
