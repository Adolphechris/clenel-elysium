## 1. Objectifs d'apprentissage

À la fin de cette leçon, l'élève sera capable de :

1. Décrire le squelette humain ;
2. Identifier les principales parties du squelette ;
3. Expliquer les fonctions du squelette.

## 4. Contenu de la leçon

### 4.1 Fonctions du squelette

Le squelette a 5 fonctions :
1. **Soutien** : maintient le corps debout.
2. **Protection** : protège les organes (crâne = cerveau, cage thoracique = cœur/poumons).
3. **Mouvement** : les muscles s'attachent aux os.
4. **Production** : la moelle osseuse produit les cellules sanguines.
5. **Stockage** : stocke le calcium et le phosphore.

### 4.2 Parties principales du squelette

| Partie | Nombre d'os | Rôle principal |
|---|---|---|
| **Crâne** | 22 | Protège le cerveau |
| **Colonne vertébrale** | 33 | Soutien, protection de la moelle |
| **Cage thoracique** | 25 (côtes + sternum) | Protège cœur et poumons |
| **Bassin** | 3 (os coxaux) | Soutien, protection organes pelviens |
| **Bras** | 64 (2 × 32) | Préhension, mouvement |
| **Jambes** | 62 (2 × 31) | Marche, saut, course |

**Total :** environ 206 os chez l'adulte.

### 4.3 Types d'os

| Type | Forme | Exemple |
|---|---|---|
| **Long** | Allongé, cylindrique | Fémur, humérus, tibia |
| **Court** | Cube | Vertèbres, poignet |
| **Plat** | Plat, large | Crâne, omoplate |
| **Irregular** | Forme complexe | Vertèbres |
| **Sésamoïde** | Dans un tendon | Rotule (patella) |

**Remarque :** Le fémur (os de la cuisse) est le plus long et le plus fort de l'adulte. Le stapes (oreille) est le plus petit.
