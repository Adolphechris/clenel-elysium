## 4. Contenu de la leçon

### 4.1 Les 3 types de muscles

| Type | Localisation | Caractéristique | Contrôle |
|---|---|---|---|
| **Strié squelettique** | Attaché aux os | Volontaire, bandé | Conscient |
| **Lisse** | Organes (estomac, intestins, vaisseaux) | Involontaire, lent | Inconscient |
| **Cardiaque** | Cœur | Involontaire, strié, ne se fatigue jamais | Inconscient |

### 4.2 Comment le muscle fait bouger l'os

- Un muscle ne peut que **tirer** (jamais pousser).
- Les muscles travaillent **par paires antagonistes** :
  - Quand un muscle se contracte, l'autre se relâche.
- Exemple au coude :
  - **Biceps** (avant-bras) : contraction → le bras se plie
  - **Triceps** (arrière-bras) : contraction → le bras se redresse

**Schéma :**
```
Biceps se contracte + Triceps se relâche → Bras plié
Biceps se relâche + Triceps se contracte → Bras droit
```

### 4.3 Les muscles principaux

| Zone | Muscle principal | Action |
|---|---|---|
| Épaule | Deltoidien | Lever le bras |
| Bras | Biceps / Triceps | Plier / Détendre le bras |
| Cuisse | Quadriceps / Ischio-jambiers | Étendre / Plier la jambe |
| Mollet | Gastrocnémi | Se lever sur les pointes |
| Visage | Zygomatique, Orbiculaire | Sourire, cligner |

**Remarque :** Le cœur est un muscle cardiaque — il bat environ 100 000 fois par jour sans jamais se reposer.
