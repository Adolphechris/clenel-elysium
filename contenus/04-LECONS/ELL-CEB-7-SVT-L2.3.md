## 1. Objectifs d'apprentissage

À la fin de cette leçon, l'élève sera capable de :

1. Expliquer les liens entre les différents niveaux d'organisation ;
2. Résoudre des exercices de hiérarchisation ;
3. Comprendre qu'un déséquilibre à un niveau affecte les autres niveaux.

## 4. Contenu de la leçon

### 4.1 Les niveaux sont interdépendants

Chaque niveau dépend du niveau inférieur et influence le niveau supérieur :

- Une **cellule** malade → le **tissu** est affecté
- Un **tissu** endommagé → l'**organe** ne fonctionne plus correctement
- Un **organe** défaillant → l'**appareil** est perturbé
- Un **appareil** en panne → l'**organisme** est malade

**Exemple concret en RDC :**
- Une cellule du rein ne filtre plus bien (cellule)
- → Le tissu rénal est endommagé (tissu)
- → Le rein ne filtre plus correctement (organe)
- → L'appareil urinaire est défaillant (appareil)
- → L'enfant est malade, doit être soigné (organisme)

### 4.2 Comment on remonte le système

Quand un être vivant est malade, le médecin cherche le niveau affecté :

1. **Symptômes** → organisme (l'enfant a de la fièvre)
2. **Organe atteint** → organe (le foie est douloureux)
3. **Tissu affecté** → tissu (le tissu hépatique est inflammé)
4. **Cellule problématique** → cellule (les hépatocytes sont endommagés)

**Remarque :** Cette approche est utilisée dans tous les hôpitaux de RDC — c'est une application directe des niveaux d'organisation.
