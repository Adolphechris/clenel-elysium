## 1. Objectifs d'apprentissage

À la fin de cette leçon, l'élève sera capable de :

1. Définir l'ensemble des nombres entiers relatifs Z ;
2. Placer des nombres relatifs sur une droite numérique ;
3. Comparer des nombres relatifs (ordre dans Z).

## 2. Situation de départ

Un élève mesure la température à Kinshasa le matin (15°C) et le soir (-3°C). Comment représenter ces valeurs ?

**Question motrice :** *Comment représenter des nombres inférieurs à 0 ?*

## 4. Contenu de la leçon

### 4.1 L'ensemble Z (entiers relatifs)

Z = {…, -3, -2, -1, 0, 1, 2, 3, …}

| Ensemble | Contient | Exemples |
|---|---|---|
| **N** (naturels) | 0 et entiers positifs | 0, 1, 2, 3… |
| **Z** (relatifs) | N + entiers négatifs | …-3, -2, -1, 0, 1, 2… |
| **Q** (rationnels) | Fractions de Z | ½, -¾, 2,5 |
| **R** (réels) | Tout ce qui est mesurable | √2, π… |

### 4.2 La droite numérique

```
←——(-4)—(-3)—(-2)—(-1)—(0)—(1)—(2)—(3)—(4)——→
```

- Les nombres **négatifs** sont à **gauche** de 0.
- Les nombres **positifs** sont à **droite** de 0.
- **0** est le point central (ni positif ni négatif).

### 4.3 Ordre dans Z

Sur la droite, **le nombre à droite est toujours plus grand** :
- -3 < -1 < 0 < 2 < 5
- Tout nombre négatif < 0 < tout nombre positif
- Pour deux négatifs : celui qui est le PLUS À DROITE est le plus grand
  → -2 > -5 (car -2 est plus à droite)

**Exemple en RDC :** La température peut descendre sous 0°C dans certaines régions (Virunga, haute altitude). -5°C est plus froid que -2°C.

## 5. Activités et exercices

| N° | Type | Énoncé | Aide / indice | Corrigé |
|---|---|---|---|---|
| 1 | Application directe | Place -3, 2, -1, 0, 5 sur la droite | §4.2 | Ordre : -3 < -1 < 0 < 2 < 5 |
| 2 | Application directe | Quel est le plus grand : -7 ou -3 ? | §4.3 | -3 > -7 |
| 3 | Réinvestissement | Range dans l'ordre croissant : 3, -5, 0, -1, 4 | §4.3 | -5 < -1 < 0 < 3 < 4 |
| 4 | Situation-problème | Le matin il fait -2°C, l'après-midi 8°C. Quelle est la variation ? | §4.3 | Variation = 8-(-2) = +10°C |
